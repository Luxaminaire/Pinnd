Project Name: Pinn-D

Team Members: Jack Dillon, Linnea Gutting, Elliot Miller, Rosemary Oswald, Joyce Yee

Project Description: Our project, Pinn-D, is an offline program that allows users to create and arrange notes called Pinns on a virtual corkboard. Our eventual goal is for each note to be fully customizable, including size, position, shape, title, text content, and attached images or sound files.

This is for Roya's CS370 class at SSU!!

This application is locally saved and will allow for:
- A corkboard background that expands indefinitely
- Pinns of varying types, including:
  - Image Pinns
  - Audio Pinns
  - Text Pinns
  - Password-protected Pinns
- Full customization of Pinns, including:
  - Moving around the board
  - Resizing (within limits)
  - Changing background colors & text properties

KNOWN ISSUES:
1. Attempting to save a blank Pinnboard with nothing on it fails.
2. No support for saving Pinnboards using a SQL database.
3. Magic numbers for recoloring different parts of a Pinn.
4. Context Menus become impossible to read when their parent object has the same background color and text color.
